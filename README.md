# Spotify Landing Page Clone 🎵

## 📌 About the Project
This project is a Spotify-inspired landing page developed using HTML and CSS. It recreates the look and feel of Spotify's web player with a dark theme, navigation header, music sections, and a sign-up banner.

## ✨ Features
- Header with Spotify logo, home button, search bar, and navigation links
- Sidebar with Your Library, playlist, and podcast sections
- Trending songs displayed as cards
- Popular artists displayed in circular cards
- Footer with useful links and social icons
- Fixed sign-up banner at the bottom
- Responsive layout for different screen sizes

## 🛠️ Technologies Used
- HTML5
- CSS3
- Font Awesome icons

## 🚀 How to Run
1. Download or clone this repository.
2. Keep the `index.html`, CSS file, and `Assets` folder in the correct locations.
3. Open `index.html` in your browser.
